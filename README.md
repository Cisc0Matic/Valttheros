# Valttheros

Dark Fantasy RPG argentino para Minecraft 1.21.1 (NeoForge 21.1.248).

Modpack tematico con lore argentino, 5 provincias, 9 comunidades, sistema de dialogos visuales, misiones y comercio entre facciones.

## Requisitos

- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.248
- **Java**: 21+
- **Launcher**: PrismLauncher (recomendado)

## Contenido

### Mods principales
- **Iron's Spells & Spellbooks** — Magia y hechizos
- **Goety** — Dark magic, cultistas, boss fights
- **Mowzie's Mobs** — Tribu Barakoa, boss creatures
- **Epic Fight + Better Combat** — Combat overhaul
- **Biomes O' Plenty** — 50+ biomas nuevos
- **Moog's Voyager Structures** — 113 estructuras
- **FTB Quests** — 35 misiones en 9 capitulos
- **VNDialog** — Dialogos visuales tipo visual novel
- **Xaero's Minimap + World Map** — Mapas y waypoints

### Comunidades (9 facciones)

| Comunidad | Mobs | Provincia |
|-----------|------|-----------|
| Tribu Barakoa | Mowzie's Barakoa | Estero |
| Culto de la Llama | Goety Warlock/Heretic | Estero |
| Agricultores del Norte | Villagers + Priest | Tucuman |
| Fuego Interior | Goety Heretics | Tucuman |
| Sabios de La Docta | Iron's Wizards | Cordoba |
| La Sombra | Goety Sorcerers | Cordoba |
| Mercaderes del Rio | Villagers + Traders | Rosario |
| Mortifagos | Iron's Necromancer | Rosario |
| Guardia Real | Priests + Villagers | Buenos Aires |

### Sistema de dialogos
- VNDialog con retratos pixel art
- Branching dialogues con opciones
- Commands que ejecutan acciones en el juego

## Instalacion

1. Descargar mods de Minecraft 1.21.1 NeoForge
2. Copiar `minecraft/config/` sobre tu instancia
3. Copiar `minecraft/datapacks/` sobre tu instancia
4. Copiar `minecraft/resourcepacks/` sobre tu instancia
5. Activar resource packs en el juego

## Estructura del repo

```
Valttheros/
├── PROGRESS.md              # Estado del modpack
├── PLAN_COMUNIDADES.md      # Plan de comunidades
├── instance.cfg             # Config de PrismLauncher
├── mmc-pack.json            # Version de NeoForge
└── minecraft/
    ├── config/              # Configs de mods
    ├── datapacks/           # Datapacks custom
    └── resourcepacks/       # Resource packs custom
```
